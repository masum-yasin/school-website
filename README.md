# Chetona Model Academy Website

Glenrich-inspired school website template with **CMA content**.

## Run locally
Open `index.html` or via Laragon:
`http://localhost/shurjo-solution-system/CHETONA%20MODEL%20ACADEMY/`

## Template match (vs glenrich.edu.bd)
- Top bar + sticky white header + orange **Apply Now**
- Dropdown nav (Strengths / Admissions)
- Hero image slider
- Why + animated stats counters
- Program highlight cards
- Facilities icon grid
- News / updates cards
- CTA band + dark footer

## Pages
`index.html` · `why-cma.html` · `about.html` · `academics.html` · `student-life.html` · `campus.html` · `admissions.html` · `contact.html`
